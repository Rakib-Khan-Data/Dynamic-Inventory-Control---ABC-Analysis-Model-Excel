# Dynamic Inventory Control & ABC Analysis Model (Excel)

## Overview
This project demonstrates an Excel-based inventory management system using ABC Analysis and dynamic Reorder Point (ROP) alerts.

## Features
- 50+ SKU inventory dataset
- Total Annual Value calculation
- ABC Classification (A, B, C)
- Cumulative Value & Percentage analysis
- Dynamic Reorder Point (ROP)
- Automatic REORDER/OK alerts
- Conditional Formatting

## Excel Functions Used
- IF()
- SUM()
- COUNTIF()
- Absolute Cell References
- Sorting
- Conditional Formatting

## Tools Used
- Microsoft Excel
